这些词在原文里反复出现，先认一遍，后面每份文档都会顺很多。

| 黑话 | 人话 |
|---|---|
| skill / 技能 | 一份说明书（SKILL.md），用斜杠命令调用，如 `/pstack:how` |
| playbook | 一类任务的步骤清单，不能直接调用，由总管按任务挑选 |
| poteto-mode | 总管。看你的任务，挑清单、派活、把关 |
| how / why | 问「现在怎么跑」/ 问「当初为什么这么写」 |
| driver | 替 AI 操作真实界面的工具：点按钮、填表、截图 |
| repro / 复现 | 让缺陷稳定出现的那套操作，修任何 bug 前的第一步 |
| 吞吐检查点 | 派活前的四问：哪些串行、哪些并行、共享状态怎么拆、最小拆分是什么 |
| Non-negotiables / 非协商项 | 硬规矩，任何情况下不许绕过 |
| subagent / 子代理 | 主会话派出去干活的分身，干完只把结论带回来 |
| worktree / 工作树 | git 的并行工作副本，给每个并行代理一份，防止互相覆盖 |
| PR | 改动请求（pull request），代码合入主线的载体 |
| CI | 提交后自动跑构建和测试的流水线 |
| merge-ready | PR 达到「可以合并」的状态；点不点合并在人 |
| 面板 panel | 同一任务起多个模型并行干，列表越长花钱越多 |
| 盲测 | 候选者不知道在被测、评委不知道答案来自哪一版的对比实验 |
| 宿主 runtime | 跑 AI 的软件：Claude Code、Codex、Pi 等 |
| instrumentation | 埋点和日志，用来看运行时真实发生了什么 |
