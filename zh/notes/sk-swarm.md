这本是「派一队工人，收割一份报告」：扇出 N 个并行子代理，每个干一小片或互相竞速，最后合并成一份会话内报告。

拆解里面的黑话：

- **切片 vs 竞速**：把任务分成不重叠的片各干一块，或者同一份简报派 N 个工人比谁先干好（first pass / rank all / best-of 三种选法要事先声明）。
- **worktree 隔离**：每个会写输出的工人分到自己可写的目录或工作树，避免互相覆盖。
- **gap**：某工人没按简报要求记录验证的 SHA 和方法，结果作废重派；重派还不行就记为缺口，缺口不算通过。

什么时候用它：横切检查要并行覆盖（全仓库找泄漏、多模块补测试）、想让几个模型竞速同一个任务。什么时候别用：想把多个候选最好的部分嫁接合并成一个产物——那是 arena；swarm 只收报告不改代码。
