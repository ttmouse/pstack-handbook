我要这个任务的更深版本，不是更大版本。重写之前，先做四件事：

1. 说明这个领域的顶尖高手在这里会做什么，而我没有要求。
2. 说出他们会从什么最原始的素材入手，而不是已经替我消化过的东西。
3. 点名他们会用的具体方法和工具。
4. 说明除了你和我之外，还有什么能证明结果是对的。

然后把我的提示词重写成恰好要求这些。

重写后的提示词要让 agent 对任何实验能裁决的选择先做原型、基于观察结果推荐一个方案。实验无法裁决的产品或偏好选择留给我来定。
