# Remove AI code slop

对照分支的基底检查 diff，清除本分支引入的 AI 赘余。基底是 PR 的 base 分支，否则是本分支切出的那个分支，否则是仓库默认分支。未提交的改动也要纳入。

## Focus Areas

- 多余的注释，或与局部风格不一致的注释
- 对可信代码路径而言反常的防御性检查或 try/catch 块
- 只为绕开类型问题而加的 `any` 断言
- 应该用提前返回简化的深层嵌套代码
- 与该文件及周边代码库不一致的其他模式

## Guardrails

- 保持行为不变，除非修的是明显的 bug。
- 优先最小、聚焦的编辑，而不是大范围重写。
- 编辑后，重跑验证该改动的检查（测试、类型检查，UI 工作则是驱动技能）并汇报结果。
- 任何检查失败的编辑一律回滚。
- 最终总结保持精炼（1-3 句）。
