# Boundary Discipline

在数据跨越系统边界的地方（CLI 参数、配置文件、外部 API、网络）做校验、收窄类型、处理错误。边界之内信任类型：不再重复校验，不再写冗余的 nil 检查。在边界把原始数据解析成领域类型，把传输层和框架类型挡在公共接口之外。业务逻辑住在没有框架依赖的纯函数里，调用它们的壳很薄。

两个检验。这份数据现在正在跨越边界吗？如果不是，这个校验是冗余的。这能成为一个壳直接调用的纯函数吗？如果能，就抽出来。
