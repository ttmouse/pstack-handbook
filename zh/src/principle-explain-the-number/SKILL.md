# Explain the Number

- **跑之前先写下判据。** 写明什么样的结果会改变决策，以及噪声底。当逐次运行的波动大于效应本身时，停止。
- **问「为什么不是翻倍？」** 从一次运行期间采到的 profile 或计数器出发，说出限制结果的那个资源或代码路径。读代码读出来的猜测不算限制因素。
- **列出这个数字还可能在测什么**（错误、被跳过或缓存的工作、从未运行过的代码、未调优的对照面、噪声、小到不重要的片段），并逐项用证据排除。
- **把运行次数、波动幅度和限制因素与数字放在一起。**

性能数字要跑 [benchmark-checklist](../benchmark-checklist/SKILL.md) 技能。eval 结果则要问：每次运行都真的完成了任务吗？差距在多次试验和多个模型上成立吗？这个场景重要吗？
