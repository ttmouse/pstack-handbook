### Visual parity

**像素级等价归你。基线就是规格，你不碰它。** 等价性靠图像 diff 验证，不靠肉眼。

1. 任何迁移之前先立基线：一个视觉回归台架，对当前组件的各个状态截图；比对两套实现时还要加上目标实现。没有基线就没有资格谈 parity。这是阻塞前置条件，不是后续补做。
2. 反走捷径条款，明说出来并守住：不改台架、不篡改基线、不为了让 diff 通过而重构组件。基线看起来不对就停下来问，不要编辑它。
3. 一次迁移一个组件。跨工作树并行，每个组件一个 owner（**separate-before-serializing-shared-state** 原则技能）。共享原语作为阻塞阶段先迁移。
4. 通过 driver skill 在匹配界面上对每个组件做图像 diff 验证。diff 非零即失败。追查像素差。每个组件用 `/loop` 循环到 diff 为零。
5. 按组件或按安全批次走 **Opening a PR** 流程。

**汇报：** 已迁移的组件、每个的 diff 结果、基线台架位置、还剩什么。
