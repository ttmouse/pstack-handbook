### 视觉对齐

**你拥有的是像素级完全等价。基线就是规格，你不碰它。** 等价性靠图像 diff 验证，不靠肉眼。

1. 先建立基线，在任何迁移之前：一个视觉回归工具，对当前组件的各个状态截图；匹配两套实现时还要覆盖目标实现。没有基线就没有对齐声明。这是阻塞性的前置条件，不是后续任务。
2. 反走捷径条款，明说并守住：不改工具，不动基线，不为了 diff 通过而重构组件。基线看起来不对就停下来问，不要改它。
3. 一次迁移一个组件。跨工作树并行，每个组件一个 owner（**separate-before-serializing-shared-state** 原则技能）。共享原语作为阻塞阶段先行迁移。
4. 通过 driver 技能在匹配面上用图像 diff 对照基线验证每个组件。非零 diff 就是失败。查清像素差。每个组件跑 `/loop` 直到 diff 为零。
5. 按组件或按安全批次执行 **Opening a PR**。

**汇报：** 已迁移的组件、每个组件的 diff 结果、基线工具的位置、还剩什么。
