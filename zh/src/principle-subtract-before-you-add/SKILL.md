# Subtract Before You Add

演进一个系统时，先移除复杂性，再构建。默认做减法。

把简化当成持续的投资。留下一个比你发现时稍微更简单、能力更强的设计，而暴露面保持不变或更小。

- 排序上先移除后构建
- 打磨之前先削减（先达到最小，再投资质量）
- 为观察到的使用方式设计，不为臆测的边界情况
- 不加规格说明之外的臆测性校验器、解析器或守卫
- 简化 prompt（删掉冗余指令和过度的模板）
- 当一个引用没有任何新内容时，删掉它，而不是留下 stub
