# Subtract Before You Add

演进系统时，先删复杂度，再构建。默认做减法。

把简化当作持续投入。离开时，让设计在相同或更小的表面积背后，比你接手时更简单、更能干。

- 先删后建
- 先砍再打磨（先到最小形态，再投入质量）
- 为观察到的使用方式设计，不为臆想的边缘情况设计
- 不加规格之外的臆想校验器、解析器或防护
- 简化提示词（去掉冗余指令和过度的模板）
- 引用没有新内容时，直接删掉，不要留桩
