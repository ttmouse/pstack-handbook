# Never Block on the Human

人类是异步监督的。代理必须保持不被阻塞。做出合理的决定，继续推进，让人类事后纠偏。代码改动是可逆、可审查的，所以一个错误决定通常比阻塞代价更低。

- 先推进，再展示。把工作做完，展示结果。不要问「我该不该做 X？」。去做 X，解释为什么。
- 让系统自愈。发现问题就记录下来，在下一轮修掉。
- 不可逆的动作（force-push、删除生产数据、向外部发消息）仍然需要确认。
- 可逆的动作（写代码、编辑笔记、拆分任务）应当直接推进，不阻塞。
- 产品方向来自人类。执行不应该阻塞。
