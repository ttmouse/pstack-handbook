# Model the Domain

把领域知识编码进数据结构，而不是散落在各处条件判断里。结构选对了，非法状态就无法被表示出来，分支也随之消失。

需要时优先选：用状态机代替散落的布尔标志或阶段检查；用带类型的模型代替松散的参数；用映射、注册表或可辨识联合代替跨文件的分支；用 reducer 代替随手写的修改逻辑；在访问模式需要的地方用索引、队列或规范化的集合。

不要硬套。形状清晰、改动局限在局部、且不太可能增长的时候，保留朴素代码；一个抽象如果没有消掉分支或非法状态、只是加了一层间接，就要警惕它。

跳过这一步的信号是：某个功能每次都要往 if/else 链上多挂一个分支，或者出现第二个必须和第一个保持同步的布尔值。
