# Fix Root Causes

修故障本身，不是修它浮现的地方。根因是系统第一次做出不该做的动作、或第一次没能处理一个本应处理的状态的地方。

- 先复现。连问「为什么」，直到答案落到代码里的一个错误决策。卡住时，插桩，去读真实的运行状态。
- 问触发症状的那个状态是否合法。合法，就在代码断掉的地方处理它；本不该存在，在那里加检查只会掩盖 bug，要去找生产它的东西。守卫、重试、吞掉的错误、钳位的值、丢弃的状态，都是藏 bug 的常见去处。
- 修模式，不修孤例。找到有同一故障的每一处。
- 如果那个决定性事实是深挖出来的，提出一个便宜、常开的信号，让它在第一眼就能被看见。
