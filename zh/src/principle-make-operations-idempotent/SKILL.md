# Make Operations Idempotent

设计每一个改变状态的操作，使它无论跑多少次、无论上一次停在哪里，都收敛到正确的状态。

每一步都从当下存在的状态推导，而不是从上一次运行想做什么推导。读当前状态，与目标比较，只应用差值。

一次运行留下的任何东西（锁、临时文件、写了一半的记录、被认领的任务），都必须能被下一次运行识别为过期，依据是在上一次可能停下的任何一个位置都成立的证据。写到临时路径，再用重命名落到位置。

检验：跑两次会怎样？如果上一次运行在每一个可能的点崩溃过呢？如果答案取决于留下了什么，就补一个对账步骤。
