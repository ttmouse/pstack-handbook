# What did I get done

## 触发

需要对某个具体时间段（例如：昨天、最近 3 天、最近一周）完成的工作做一份简短、高信号的总结。

## 工作流

1. 把请求的时间窗口解析为具体的日期。
2. 读取当前 git 用户邮箱在该范围内提交的 commit。
3. 排除 merge commit 和未提交的改动。
4. 把最重要的已上线改动综合成一份简明的状态更新。
5. 在最终总结里写明实际使用的日期范围。

## 护栏

- 极其简练且信息密集。
- 优先写实质的行为或架构改动。
- 忽略纯外观的改动（格式化、imports、小改名）。
- 不推断意图或动机。从功能上描述改动。

## 输出

- 一段适合放进状态更新的简短总结
- 真实的日期范围
- 可选的 2-5 条要点，只写重大改动
