# What did I get done

## 触发

需要对特定时间范围（比如：昨天、过去三天、上周）内完成的工作做一份简短、高信号的摘要。

## 工作流

1. 把请求的时间窗口换算成具体日期。
2. 读取该范围内由当前 git 用户邮箱完成的 commit。
3. 排除 merge commit 和未提交的改动。
4. 把最重要的已交付改动综合成一份简明的状态更新。
5. 最终摘要里写明实际使用的日期范围。

## 护栏

- 极度精简，信息密度要高。
- 优先写有分量的行为或架构改动。
- 纯外观改动（格式化、import 调整、小重命名）不写。
- 不推断意图或动机。只从功能角度描述改动。

## 输出

- 一份适合放进状态更新的简短摘要
- 真实的日期范围
- 可选的 2-5 条要点，只列重大改动
