# Sequence work into verifiable units

把工作排成一个个小单元，每个单元都结束在一个可检查的状态上，当前单元不通过就不前进。

在批量清扫、迁移或成批相似修改中，每个单元都是一个括号：已知良好的状态、一处改动、跑检查、继续。即使修改是工具自动做的，逐单元检查也要照跑。

按能证明工作的顺序交付：先给失败的测试，再给修复。先做减法，再做重塑。先立基线，再上处理。每个提交都各自站得住。
