# pstack 学习手册

单文件手册，依据本机安装的 pstack 0.9.129 写成。

线上版：https://ttmouse.github.io/pstack-handbook/
本地打开：双击 `index.html`，或浏览器打开 `file:///Users/douba/Projects/pstack-handbook/index.html`。
样式与插图全部内联，页面不加载任何外部资源。

内容：
- 0 读法
- 0.5 十分钟一个故事（零术语入口，配六步流程图）
- 1 四层结构（配结构图）
- 2 技能如何运行（配一次任务流程图、上下文占用对比图）
- 3 二十三本 playbook（修缺陷六步图含两个回环，做功能八步图含检查点四问）
- 4 四十三技能全解（带过滤框）
- 5 二十四条原则（配三条核心原则的落点图）
- 6 五条心法
- 7 验证体系（配验证链路图与两种失败来源）
- 8 并行与规模（配并行四问决策图）
- 9 成本与失败模式（配「该不该走流程」判定图）
- 10 纸笔课
- 11 实操课
- 12 七天计划
- 13 费曼层：讲回去（配费曼循环图；复述卡、讲错诊断、四问自评）
- 14 原作者的案例（八个小故事，标注二手与未核实）
- 15 别人的判断（第三方分析，配四级顺序阶梯图与成本放大图）
- 16 外循环：需求之前那一环（配两条环图；五个动作、固定闭环、信任四步、本地最小替代）
- 附录 命令速查、文件地图、术语表

`src/` 是生成用的分片，`src/figs/` 是生成的图。重新构建：

```bash
python3 tools/diagrams.py   # 生成 14 张 SVG，越界与文字超宽会报错
python3 tools/build.py      # 拼接 shard、内联图、校验锚点与标签
```

图是内联 SVG，颜色走 CSS 变量，深浅色和打印都跟随；不依赖任何外部资源。

版式：正文 37em 单栏，章号挂在左外侧，标题用宋体、正文用系统黑体；图与表格比正文宽一档，代码块再宽一档。

手机阅读：顶部一条栏显示当前章，点开是完整目录，选中即收起；图先按整幅缩到屏宽，轻点放大到原尺寸并可左右滑动；表格在窄屏折成上下排列，每格用表头当标签，不横向截断。
`_data.json` 是从插件抽取的技能与 playbook 元数据，供核对。
